# Hiragana chart

Learn order: rows top to bottom (lessons 1–3), then voiced sounds (lesson 4), then combinations (lesson 5).

## Basic (46)

| | a | i | u | e | o |
|-|---|---|---|---|---|
| — | あ a | い i | う u | え e | お o |
| k | か ka | き ki | く ku | け ke | こ ko |
| s | さ sa | し shi | す su | せ se | そ so |
| t | た ta | ち chi | つ tsu | て te | と to |
| n | な na | に ni | ぬ nu | ね ne | の no |
| h | は ha | ひ hi | ふ fu | へ he | ほ ho |
| m | ま ma | み mi | む mu | め me | も mo |
| y | や ya | | ゆ yu | | よ yo |
| r | ら ra | り ri | る ru | れ re | ろ ro |
| w | わ wa | | | | を o |
| | ん n | | | | |

Particles: **は** = *wa*, **へ** = *e*, **を** = *o*.

## Small っ

Doubles the next consonant: いっきょう *ikkyō*, ぼっけん *bokken*.

## Long vowels

| Sound | Written | Example |
|-------|---------|---------|
| ā | ああ | おかあさん *okāsan* |
| ī | いい | いいえ *iie* |
| ū | うう | こきゅう *kokyū* |
| ē | えい (usually) | せんせい *sensē* |
| ō | おう (usually) | どうじょう *dōjō* |

## Practice tips

- Stroke order animations: search any character at [jisho.org](https://jisho.org).
- Write each character 10 times while saying it.
- Test yourself with the dojo words in the [glossary](glossary.md): cover the hiragana column, write it, compare.
